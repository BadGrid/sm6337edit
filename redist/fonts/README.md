# Шрифты шага печати

`sm6337-10.ttf`, `sm6337-12.ttf`, `sm6337-17.ttf` — три моноширинных шрифта для экрана: при одной
высоте знака у них разная ширина, что соответствует шагу печати 10, 12 и 17 знаков на дюйм.
Программа подключает их при запуске (если файлы лежат рядом с exe) и снимает при выходе; если
файлов нет, используются системные шрифты.

Это производные от **Noto Sans Mono** (© The Noto Project Authors), лицензия **SIL Open Font
License 1.1** (`OFL.txt`). Изменения: взяты статические экземпляры переменного шрифта
(ширина 100 → 10 cpi, 62,5 → 12 cpi; 17 cpi — ширина 62,5 с дополнительным горизонтальным сжатием
контуров), набор знаков урезан до CP1251, отброшены таблицы OpenType-возможностей, добавлены
подсказки для отрисовки (ttfautohint), шрифты переименованы в «SM6337 Mono 10/12/17».
Оригинал: https://github.com/notofonts — в форме google/fonts, каталог `ofl/notosansmono`.
