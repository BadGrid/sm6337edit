# Дамп ПЗУ символогенератора СМ6337

- `1.BIN`, `2.BIN`, `9.BIN` — три образа по 8 КБ; `cm6337st.zip` — архив с теми же тремя файлами.
- Схема хранения знаков в этих образах пока не расшифрована. Картинки, которые
  строились в попытках её найти (визуализации образов с разной шириной строки, «листы
  знаков»), убраны из дерева: на них не получилось ничего похожего на буквы. Они остаются
  в истории git, если понадобятся, — `git log -- rom/`.
- Программа эти файлы не использует: шрифт печатает сам принтер (программа шлёт ему
  ESC/P-команды), а для предпросмотра берётся обычный Courier New.
