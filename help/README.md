# Справка (WinHelp, .hlp)

Здесь лежат исходники встроенной справки: `sm6337edit.rtf` (темы), `sm6337edit.hpj`
(проект) и `sm6337edit.cnt` (оглавление, нужно и при работе программы).

Скомпилировать `.hlp` можно только на Windows: нужен Microsoft Help Workshop
(`hcw.exe`, бесплатный, есть на сайте Microsoft и в составе старых Visual Studio/SDK).

1. Открыть `sm6337edit.hpj` в Help Workshop, нажать **Compile** (или из консоли
   `hcrtf -x sm6337edit.hpj`).
2. Получившийся `sm6337edit.hlp` положить в `redist/` и закоммитить — сборка
   (`make` и GitHub Actions) копирует его в `build/` рядом с exe, вместе с
   `sm6337edit.cnt` из этой папки.
3. Ошибки компиляции, если будут, пишутся в `hcw.err` рядом с проектом.

В программе справка открывается на F1 или Справка → Содержание. Если файла
`sm6337edit.hlp` рядом с exe нет, программа сообщит об этом.

Файлы `sm6337edit.rtf`/`.hpj`/`.cnt` записаны в кодировке CP1251 (русский текст).
